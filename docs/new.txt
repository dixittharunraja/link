# Feature Specification: Continuous Folder Sync (Smart Mirroring)

## Overview
Continuous Folder Sync is a zero-cloud, peer-to-peer background folder mirroring engine for Link. It automatically synchronizes designated directories across trusted devices (PC <-> Mobile <-> TV) in real time over local Wi-Fi without relying on central servers or cloud providers.

---

## 1. How It Works (Architecture)

1. **Trust & Discovery**: Uses Link's existing **Trusted Pool** (Ed25519 root trust + TLS 1.3 pinned certs) for automatic device authentication.
2. **Real-Time Event Detection**: Listens to OS filesystem events (`chokidar` / `ReadDirectoryChangesW` on Windows, `FileObserver` / `WorkManager` on Android) to detect file changes instantly upon saving.
3. **High-Throughput Transfer**: Streams modified files over Link's existing **ephemeral binary TLS channels** (128 KB buffers) bypassing JSON overhead for maximum LAN speed.
4. **Offline Queueing**: If a peer is offline when a file is edited, Link queues the change and syncs automatically when both devices reconnect to the same mesh.
5. **Conflict Resolution**: If a file is modified on both devices while disconnected, Link preserves both versions by creating `filename (Conflict YYYY-MM-DD).ext` to ensure zero data loss.

---

## 2. User Experience Flow

1. **Setup**: User opens **Folder Sync** tab in Link, selects a local directory and a target device/folder from their Trusted Pool, and sets sync direction (*Two-Way*, *Send Only*, or *Receive Only*).
2. **Auto Configuration**: Link syncs the folder pairing configuration to the peer over the TLS control channel automatically.
3. **Background Execution**: Files sync silently in the background when edited. A micro-toast notification confirms transfer completion.

---

## 3. Hardware & Application Overhead

- **App Size Impact**: + ~1.0 MB (Desktop) / + ~300 KB (Mobile).
- **CPU & RAM**: < 0.5% CPU when idle; ~15-20 MB RAM overhead.
- **Battery Impact (Android)**: Minimal (< 1-2% daily) by utilizing native event observers instead of continuous polling.
- **Network Overhead**: 0 KB background usage when idle; fully saturates local Wi-Fi bandwidth during active syncs.

---

## 4. Comparison: Link vs. Syncthing

| Aspect | Syncthing | Link Continuous Sync |
| :--- | :--- | :--- |
| **Architecture** | P2P (Block-level Delta Sync) | P2P (Event-driven File Streaming) |
| **Trust Model** | Manual Device ID exchange & approval | Automated via Link Trusted Pool |
| **Setup Complexity** | Multi-step QR scanning + Web GUI | 3-click folder mapping within Link UI |
| **Ecosystem** | Standalone file sync app | Integrated into Link mesh (Clipboard, Remote Mic, Controls) |
