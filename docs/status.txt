# Topology Status Tracker

This file documents the end-to-end verification status and topology capabilities of every feature in the Link project.

## Trust Model — Trusted Pool (verified on hardware)

Your devices form a **Trusted Pool** of your own devices, all mutually trusted. Trust flows through
a single shared **owner key** (a per-person Ed25519 root of trust), not peer-to-peer. Pairing any
one pool member (one PIN — the human gate) enrolls a newcomer: that member hands over the owner key
and issues an owner-signed **membership certificate** binding the newcomer's TLS identity to the
pool. Every other member then auto-trusts it by verifying that cert against the owner key it already
holds — **no second PIN**. Removing a device owner-signs a revocation that gossips across the pool.
Friends' devices never join the pool; casual sharing (Tools: File Transfer / Audio Relay) is
isolated and never writes the trust store. Core: `core/pool.ts` + `LinkPool.java` (byte-identical
signed-message format), wired into the handshake by `device-manager.ts` / `LinkDeviceManager.java`.
Verified end-to-end on real hardware (desktop <-> Android): pair, enroll-via-any-member auto-mesh,
and removal all working. Deferred hardening: owner-key encryption-at-rest, full "reset pool" re-key.
