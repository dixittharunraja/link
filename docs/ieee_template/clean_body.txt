Users routinely work across a personal mix of laptops, phones, and desktop computers, expecting them to share clipboards, stream files, and forward inputs over a local network. Yet establishing secure mutual trust across these devices on a home or office LAN remains an unsolved operational problem. Current ecosystems force an uncomfortable compromise: commercial tools (such as Apple Continuity and Google Quick Share) rely on cloud identity servers that leak metadata and fail when offline, while decentralized tools (such as KDE Connect) enforce pairwise Trust-on-First-Use (TOFU) that requires (N^2) manual pairing operations. This paper presents Transitive Trust-on-First-Use (T-TOFU), a zero-coordinator trust framework designed for personal device meshes. Under T-TOFU, a user performs an out-of-band verification ceremony on a single gateway device, which automatically enrolls the newcomer across the entire mesh. We introduce a canonical pool digest ( ) computed over sorted device fingerprints, coupled with anti-entropy heartbeat gossip, to keep the trust state synchronized across dynamic LAN nodes without an online certificate authority. We also detail a flooded revocation mechanism that deterministically purges de-authorized nodes. We built and evaluated T-TOFU within Link, an open-source cross-platform runtime for Windows and Android. Our measurements show that T-TOFU reduces human pairing complexity to (1) marginal effort per device while achieving sub-100ms pool convergence with under 0.05 , of background network overhead. Commercial device-sync ecosystems, such as Apple Continuity/AirDrop, Google Quick Share, and Microsoft Phone Link, bypass the usability barrier by tying all endpoints to a corporate account (Apple ID or Google Account). While setup is easy, this model forces devices to contact remote WAN infrastructure, leaks user identity metadata over wireless advertisements~ , creates a central point of failure, and locks consumers into a single vendor's operating system. On the other hand, decentralized tools like KDE Connect~ and Bluetooth Personal Area Networks~ avoid cloud dependencies by pairing devices directly with self-signed certificates. The downside is steep: pairing is strictly pairwise. Setting up N devices requires N(N-1)/2 separate pairing steps. In a household with five personal devices, the user must perform ten distinct manual verification ceremonies. Under such friction, users routinely skip certificate fingerprint comparisons~ , leaving connections exposed to trivial on-path attacks. However, PGP required users to manually configure trust depths and understand key validity, which proved overly burdensome for typical users~ . Stajano and Anderson introduced the policy for ad-hoc wireless peripherals~ , where devices imprint permanently on a master node via physical touch. T-TOFU adapts this philosophy for symmetric, multi-master personal device meshes where no single machine serves as a permanent master. Syncthing offers an ``introducer'' flag where one device shares its known peer list~ ; T-TOFU makes all members symmetrical introducers while adding digest-based consistency checking and cascaded revocation. : Existing cross-platform integration suites include KDE Connect~ and Apple AirDrop~ . T-TOFU eliminates both the pairwise pairing penalty and cloud metadata exposure. This paper introduced , a coordinator-free trust architecture that resolves the Usable-Security Trilemma in personal device networks. By unifying human-in-the-loop gateway pairing, canonical pool digest gossip, and flooded certificate revocation, T-TOFU eliminates the (N^2) pairing bottleneck while preserving strict local-first privacy and TLS 1.3 cryptographic integrity. We verified T-TOFU across Windows and Android in the open-source Link ecosystem, demonstrating sub-100ms mesh convergence and low network overhead. Future work includes formalizing the state machine in automated protocol verifiers like ProVerif, as well as integrating threshold cryptography for shared multi-user home environments.
